# DecentraBank 🏦

### A Decentralized Banking Application Using Blockchain Technology

DecentraBank is a blockchain-based decentralized application (DApp) built using **Solidity, Truffle, Ganache, Web3.js, and MetaMask**. It demonstrates how smart contracts can support banking-related operations through a responsive web interface connected to a local Ethereum-compatible blockchain.

The project explores smart contract development, blockchain transactions, and frontend-to-blockchain integration in a local development environment.

> **Disclaimer:** This is an educational project. It is not a production banking application, and its smart contracts have not been professionally audited for real-money use.

## ✨ Features

- 🔗 **Wallet Integration:** Connect a compatible Web3 wallet, such as MetaMask.
- 👤 **Account Management:** Manage banking accounts associated with blockchain wallet addresses.
- 💰 **Deposits:** Demonstrate deposit operations through smart contract functionality.
- 💸 **Withdrawals:** Support withdrawals subject to the smart contract's validation rules.
- 🔄 **Internal Transfers:** Demonstrate balance transfers between registered accounts.
- 📊 **Balance Tracking:** Display account balance information through the frontend.
- 🌐 **Interactive Dashboard:** Use a responsive web interface to interact with the application.
- ⛓️ **Local Blockchain:** Develop and test blockchain functionality using Ganache.

*Note: The availability of each feature depends on the functionality implemented in the current smart contract and frontend.*

## 🏗️ System Architecture

The application connects the frontend to a smart contract deployed on a local blockchain.

```text
           User
             |
             v
      Web Dashboard
   (HTML, CSS, JavaScript)
             |
             v
      MetaMask / Web3.js
             |
             v
       Bank Smart Contract
           (Solidity)
             |
             v
       Ganache Blockchain
```

### How It Works

1. The user opens the banking dashboard in a web browser.
2. The user connects a compatible wallet if required.
3. The frontend communicates with the deployed smart contract through Web3.js.
4. The smart contract processes supported banking operations according to its programmed rules.
5. The application displays relevant account and transaction information.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sssSharvari/DecentraBank.git
cd DecentraBank
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start Ganache

Open Ganache and start a local blockchain. Ensure the RPC endpoint matches the configuration in `truffle-config.js`.

The previously used endpoint was:

```text
http://127.0.0.1:7545
```

### 4. Compile the smart contract

```bash
truffle compile
```

This compiles the Solidity contracts and generates the artifacts needed for deployment.

### 5. Deploy the smart contract

```bash
truffle migrate --reset
```

After deployment, make sure the frontend uses the correct contract address and ABI for the deployed contract.

### 6. Start the frontend

From the project root, run:

```bash
python -m http.server 5500 --directory src
```

Open the application in your browser:

http://localhost:5500

If wallet integration is enabled, connect MetaMask to the appropriate local blockchain network and use a Ganache test account.

## 🧪 Testing

Truffle provides a framework for testing smart contracts. Run:

```bash
truffle test
```

Recommended test cases include:

- Account creation
- Deposit and balance updates
- Withdrawals within the available balance
- Invalid transaction amounts
- Transfers between registered accounts
- Insufficient-balance handling
- Unauthorized operation handling, where applicable

Automated tests should be added and executed before reporting test results. Do not claim that all tests pass unless they have been run successfully.

## 🔐 Security Considerations

- Use test accounts and test funds on the local blockchain.
- Never commit private keys, wallet seed phrases, or passwords.
- Validate transaction amounts and account states.
- Review smart contract access controls and authorization.
- Test failure conditions and potential smart contract vulnerabilities.
- Do not use this educational application to hold real funds.
